AION2 ENGINE.INI OPTIMIZER

그래픽 최적화 설정 생성기

기존 NotMeter 생성값과 프리셋을 기준으로 그래픽카드와 목적에 맞는 engine.ini 값을 생성합니다. 검증되지 않은 렌더 경로·RHI·프레임 생성 강제값은 추가하지 않습니다.

적용 전 확인 적용 전 원본을 백업하고, 생성된 시작/종료 마커 블록만 파일 맨 아래에 추가하세요. 업스케일러와 게임 내 해상도 설정은 강제로 바꾸지 않습니다.
QUICK SETUP

세 가지만 선택하면 추천 설정이 완성됩니다

실제 게임 화면을 부정확하게 흉내 내지 않고, 그래픽카드·사용 목적·현재 증상을 기준으로 안전한 값만 생성합니다.

4

ENGINE.INI LOCATION

engine.ini 위치와 적용 방법

아래 경로를 그대로 복사하면 아이온2 설정 폴더를 바로 찾을 수 있습니다.

%LOCALAPPDATA%\AION2\Saved\Config\Windows\engine.ini

실제 경로 예시: C:\Users\Windows계정\AppData\Local\AION2\Saved\Config\Windows\engine.ini

  1. 1윈도우키 + R을 누르고 위 경로를 붙여넣어 파일을 엽니다.
  2. 2수정 전 engine.ini를 복사해 백업합니다.
  3. 3생성값을 파일 맨 아래에 붙여넣고 저장한 뒤 게임을 재실행합니다.

파일이 보이지 않으면 아이온2를 한 번 실행한 뒤 정상 종료하고 다시 확인하세요.

필수
중요 · 저장 후 반드시 파일을 읽기 전용으로 설정하세요.

생성값을 저장한 뒤 engine.ini 우클릭 → 속성 → 읽기 전용 체크 → 적용 순서로 설정합니다. 읽기 전용을 설정하지 않으면 아이온2 실행 또는 그래픽 옵션 변경 시 적용값이 초기화될 수 있습니다.

RESULT

RTX 5060 / 5070 균형

균형값으로 생성됩니다.

검증된 설정 이름과 허용 범위만 생성합니다.

적용·정리·되돌리기 안내 처음 적용할 때만 펼쳐보세요.

적용 방법

  1. 윈도우키 + R을 누르고 %localappdata% 입력
  2. AION2\Saved\Config\Windows\engine.ini 열기
  3. 기존 파일을 복사해 백업
  4. 구버전의 무마커 NotMeter 설정은 아래 안내대로 먼저 정리
  5. 기존 마커 블록이 있으면 시작/종료 마커 범위만 교체
  6. 아래 생성값을 파일 맨 아래에 붙여넣고 게임 재실행
구버전 설정 정리 engine.ini에서 다음 구버전 제목을 먼저 찾으세요. ; ===== NOT METER AION2 그래픽 최적화 : 이 제목이 있으면 새 값을 바로 덧붙이지 마세요. 백업 후 바로 앞 [SystemSettings]부터 구버전의 마지막 r.CreateShadersOnLoad=... 줄까지만 제거하고, 그 범위 밖의 기존 설정은 유지한 뒤 새 마커 블록을 붙여넣으세요.
되돌리기 ; NOT METER OPTIMIZATION START부터 ; NOT METER OPTIMIZATION END까지만 삭제한 뒤 게임을 다시 실행하세요. engine.ini 전체를 삭제하지 마세요.

맵 이동 직후 화면이 멈춤순간 끊김 방지 +1, VRAM 기준을 실제 VRAM으로 선택
배경 깨짐이 거슬림안개를 `일부 유지` 또는 `기본 유지`로 변경
필드에서 렉이 심함수풀/필드 오브젝트 -1, 후처리 깊이 -1, 스킬 이펙트 -1
물가/성역에서 렉물/반사를 `끄기` 또는 `낮게`, 그림자/반사 -1
발열과 팬소음프레임 제한 60~90 FPS, 해상도 스케일 -1
캐릭터가 늦게 선명해짐캐릭터/NPC 거리 +1, 텍스처 안정성 +1
스킬 입력이 둔함입력 반응을 `반응속도 우선`으로 변경
